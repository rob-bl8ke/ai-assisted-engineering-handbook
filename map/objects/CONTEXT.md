# Objects — CONTEXT

Every durable noun in this repo lives here as a card. Two clusters: **knowledge-types** (the artifact kinds that structure the handbook) and **workflows** (the core methods and practices the handbook documents).

## Inputs

- `map/_meta/schema.md` — node types and required frontmatter

## Reading order for a cold agent

1. Open `_index.md` to locate the noun by name.
2. Follow the link to the card.
3. The card's **See → Source** points at the authoritative file.

## Outputs

Cards are the stable reference. They do not reproduce source content — they point at it and state what moves when it changes.

## Human check

After adding or updating a card: verify the **If you change this → Hits** list against the actual source file before marking `status: verified`.
